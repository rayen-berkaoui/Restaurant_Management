# 🍽️ Restaurant Management System

A modern Restaurant Management System built with Laravel that allows restaurants to manage tables, orders, menus, categories, customers, and administrative operations through an intuitive dashboard.

## 🚀 Features

### Customer Side

* Browse restaurant menu
* View menu categories
* Scan QR code from table
* Place orders directly from mobile
* Order tracking
* Responsive design for mobile and desktop

### Restaurant Staff

* Manage customer orders
* Update order status
* View active and completed orders
* Table management
* Real-time order processing

### Admin Dashboard

* Dashboard overview and statistics
* Manage menu categories
* Manage menu items
* Manage restaurant tables
* Generate QR codes for tables
* Manage orders
* Manage users and staff
* Revenue and sales monitoring
* System configuration

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/rayen-berkaoui/Restaurant_Management.git
cd Restaurant_Management
```

### Install Dependencies

```bash
composer install
npm install
```

### Environment Setup

Copy environment file:

```bash
cp .env.example .env
```

Generate application key:

```bash
php artisan key:generate
```

Configure database settings inside `.env`.

### Run Migrations

```bash
php artisan migrate
```

### Seed Database (Optional)

```bash
php artisan db:seed
```

### Build Assets

```bash
npm run build
```

### Start Development Server

```bash
php artisan serve
```

Application will be available at:

```
http://127.0.0.1:8000
```

## 📱 QR Code Ordering System

Each table can have a unique QR code generated by the administrator.

Workflow:

1. Customer scans QR code.
2. Menu opens automatically.
3. Customer places order.
4. Kitchen/staff receives order.
5. Order status is updated in real time.
